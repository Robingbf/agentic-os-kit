# Skills catalog

Skills are on-demand tasks (`.claude/skills/<name>/SKILL.md`). Good skills are **repeated**, have a clear
input and a clear output, and save at least 10 minutes each time.

| Skill | Input | Output |
|---|---|---|
| Where did I stop? | a project / area name | last journal, open tasks, recent files — in 10 lines |
| Brief me on <person/client> | a name | one page from their folder, recent mail, calendar |
| Draft a reply | a mail thread | a draft (never sent) in their tone |
| Meeting prep | next calendar event | agenda, context, open questions |
| Notes → tasks | a notes file or pasted text | checkboxes added to the right area's State file |
| Repurpose content | a script / article / video transcript | posts for each platform, in their voice |
| Proposal / quote | client + scope | a document from their template |
| Summarise a document | a PDF / link | key points + what it means for them |
| Weekly update | journals + goals | an update for a partner, manager or investors |
| Release notes | git log since a tag | user-facing release notes |
| Tailor CV | a job offer | a CV variant + cover letter draft |
| Expense check | a statements folder | categorised summary (never moves money) |

Write the `description` so Claude knows when to use it ("Use when the user says …").
